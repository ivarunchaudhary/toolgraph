Three steps, and it gets better as your agent works.

You keep your MCP servers and your agent. ToolGraph sits in front of the tool list and decides what goes into context.

  1. Connect your servers

    Bring the tool lists from the MCP servers your agent already uses. ToolGraph reads each tool's inputs and outputs and stores them as a typed graph in HydraDB.

    • Run toolgraph sync to upload every MCP server you already use in Claude Code, Claude Desktop or Cursor
    • Paste a tools/list response
    • Import from an MCP server URL
    • Pick a preset like GitHub, Slack or Linear

  2. Your agent calls find_tools

    Add one MCP server to your agent. Before any multi-tool task, it asks for the tools it needs and gets back a short list, with the reason each tool is there.

    find_tools({
  task: "post open PRs to #eng"
})

  3. report_outcome teaches it

    When the task is done, the agent reports which tools it called and whether it worked. Chains that worked get stronger; ones that failed get weaker.

    report_outcome({
  task, success: true,
  tools: ["slack.list_channels",
          "slack.post_message"]
})

Search finds the tool. The graph finds what it needs.

Ask an agent to post to #eng. Vector search finds slack_post_message, but that tool wants a channel_id like C024BE91L, and the agent only has a channel name.

The tool that turns a name into an id, slack_list_channels, doesn't sound anything like "post a message", so similarity search leaves it out. The agent guesses, or stalls.

ToolGraph stores which tool produces each typed input and which tools consume it. When a matching tool needs something the agent doesn't have, the producer comes along, marked as a prerequisite.

Works with the agent you already use.

ToolGraph is a standard MCP server over HTTP. Add it to Claude Code, Claude.ai, Cursor or any MCP client, next to the servers your agent calls.

Your dashboard fills in your real key. Routing never calls an LLM, so you never hand us one.

Run this once in your terminal.

claude mcp add --transport http --scope user toolgraph {origin}/mcp --header "Authorization: Bearer tg_your_key"

In Claude.ai, open Settings, then Connectors, then Add custom connector, and paste your secret URL. It contains your key, so treat it like a password.

{origin}/mcp/tg_your_key

Add this to ~/.cursor/mcp.json.

{
  "mcpServers": {
    "toolgraph": {
      "url": "{origin}/mcp",
      "headers": { "Authorization": "Bearer tg_your_key" }
    }
  }
}

Point any Streamable HTTP MCP client at {origin}/mcp with a Bearer key, or call the REST API directly.

curl -s {origin}/v1/find_tools \
  -H 'Authorization: Bearer tg_your_key' \
  -H 'content-type: application/json' \
  -d '{"task": "post the open PRs in acme/api to #eng on slack"}'
